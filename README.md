# Drawing Happiness

พื้นที่สำหรับคนที่สนใจในงานสร้างสรรค์ — ศิลปะ การออกแบบ และไอเดียใหม่ๆ

เว็บไซต์หน้าเดียวแบบ static สร้างด้วย HTML, CSS และ JavaScript ไม่ต้องติดตั้ง dependencies

## เปิดดูในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ หรือรัน local server:

```sh
python3 -m http.server 8000
```

แล้วเข้า `http://localhost:8000`
